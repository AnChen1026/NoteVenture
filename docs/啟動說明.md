# NoteAdventure｜啟動說明

本文件說明**本機開發**與**雲端 Flask（學生端）**的開啟方式。  
老師端為 Streamlit；學生端為 Flask 提供的 HTML 一頁版。兩者共用同一套 Flask API。

| 角色 | 介面 | 入口 |
|------|------|------|
| 學生 | Flask HTML／CSS／JS 一頁版 | `/student/app`（或 `/student`） |
| 老師 | Streamlit | `streamlit run streamlit_app.py` |

---

## 一、本機開啟

### 1. 環境準備

```bash
git clone <repository-url>
cd NoteAdventure
```

Windows：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 資料庫

1. 建立 MySQL 資料庫（建議名稱 `music_rpg_v2`）
2. 執行：

```text
sql/music_rpg_schema_v2.sql
```

3. 在專案根目錄建立 `config.ini`（**不要提交到 Git**）：

```ini
[DB]
host=localhost
user=root
password=your_password
port=3306
database=music_rpg_v2
```

### 3. 啟動 Flask（一定要先開）

```bash
flask --app app run --port 5000
```

自測：瀏覽器開 `http://127.0.0.1:5000/api/health`

### 4. 學生端

瀏覽器開啟：

```text
http://127.0.0.1:5000/student/app
```

一頁版外殼會以 iframe 載入登入、主頁、琴房等內頁。  
頂層若直接開舊路徑（如 `/student/login`），通常會導回一頁版。

### 5. 老師端（另開一個終端機）

預設連本機 Flask `http://127.0.0.1:5000`：

```bash
streamlit run streamlit_app.py
```

瀏覽器通常開啟 `http://localhost:8501`。

本機架構：

```text
本機 Streamlit（老師）──HTTP──→ 本機 Flask API ──→ 本機 MySQL
本機瀏覽器（學生） ──────────→ 本機 Flask 學生頁 ──→ 同一套 API／DB
```

## 二、雲端 Flask 開啟（學生 UI + API）

目標（方案 B）：

- **雲端**：MySQL + Flask（學生頁／API）
- **本機**：Streamlit 老師端，連到雲端 Flask

學生開啟：`https://你的網域/student/app`

### 1. 雲端 MySQL

1. 建立資料庫（建議 `music_rpg_v2`）
2. 執行 schema：
   - 一般環境：`sql/music_rpg_schema_v2.sql`
   - Railway 等需「單句執行、勿含 CREATE DATABASE」時：可用 `sql/music_rpg_schema_railway.sql`
3. 記下 `host`、`port`、`user`、`password`、`database`

### 2. 部署 Flask

啟動指令（例：Railway／Render）：

```bash
gunicorn -w 2 -b 0.0.0.0:$PORT "app:create_app()"
```

若平台沒有 `$PORT`：

```bash
gunicorn -w 2 -b 0.0.0.0:5000 "app:create_app()"
```

### 3. 必填環境變數

| 變數 | 說明 |
|------|------|
| `NOTEADVENTURE_DB_HOST` | MySQL host |
| `NOTEADVENTURE_DB_PORT` | 通常 `3306` |
| `NOTEADVENTURE_DB_USER` | 資料庫帳號 |
| `NOTEADVENTURE_DB_PASSWORD` | 資料庫密碼 |
| `NOTEADVENTURE_DB_NAME` | 例如 `music_rpg_v2` |
| `NOTEADVENTURE_SECRET_KEY` | 長隨機字串（登入 cookie） |
| `NOTEADVENTURE_COOKIE_SECURE` | HTTPS 時設 `1` |

雲端用環境變數即可，**不要**把 `config.ini` 上傳到 GitHub。

### 4. 部署後自測

1. `https://你的網域/api/health`
2. `https://你的網域/student/app`
3. 手機測琴房錄音（建議 HTTPS）

### 5. 本機老師端連雲端 Flask

PowerShell：

```powershell
$env:NOTEADVENTURE_API_BASE_URL = "https://你的Flask網域"
streamlit run streamlit_app.py
```

雲端架構：

```text
本機 Streamlit（老師）──HTTP──→ 雲端 Flask API ──→ 雲端 MySQL
學生瀏覽器 ───────────────→ 雲端 Flask 學生頁 ──→ 同一套 API／DB
```

### 6. 上線檢查清單

- [ ] 雲端 MySQL 已建表
- [ ] 環境變數齊全，`SECRET_KEY` 非預設
- [ ] HTTPS 時 `COOKIE_SECURE=1`
- [ ] 學生可登入、看任務、上傳練習
- [ ] 本機 Streamlit 連雲端後可建學生／派任務
- [ ] 密碼與 `config.ini` 未進 Git

### 7. 常見問題

**本機開發還能用 `config.ini` 嗎？**  
可以。未設資料庫環境變數時，`db.py` 仍讀本機 `config.ini`。

**錄音檔存在哪？**  
伺服器 `uploads/`。免費方案重部署後檔案可能消失；之後可再改雲端物件儲存。

**只要測學生，一定要開 Streamlit 嗎？**  
不用。Streamlit 可留在本機，需要管理時再開。
